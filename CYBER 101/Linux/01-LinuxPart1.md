
  ### Linux Machine

A **Linux machine** is a computer/server that runs a Linux-based operating system, such as Ubuntu, Kali Linux, Debian, or CentOS.

In cybersecurity, Linux machines are commonly used for:
- Running security tools
- Connecting to remote servers
- Managing servers
- Performing network/security testing


## `whoami`

The `whoami` command shows the **username of the currently logged-in user**.

```bash
whoami
```
## `echo`

`echo` is used to **display text or variable values** in the terminal.

```bash
echo <text>
```
