### Python: Simple Demo

random → Import random number library.
random.randint(1,20) → Generate a random number.
secret → Stores the secret number.
guess → Stores the user's guess.
tries → Counts attempts.
input() → Reads user input as text.
int() → Converts text into a number.
tries = tries + 1 → Increases the attempt counter.

## How it works
The computer secretly chooses a random number between 1 and 20.
The user guesses the number.
The program stores the guess.
The program counts how many guesses the user has made.
