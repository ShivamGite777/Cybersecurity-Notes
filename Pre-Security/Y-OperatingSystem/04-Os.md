## security Goals (CIA Triad)

Security focuses on protecting:

* **Confidentiality** → Keep data private.
* **Integrity** → Prevent unauthorized changes.
* **Availability** → Keep systems and data accessible.

 # Confidentiality: You want to ensure that secret and private files and information are only available to intended persons.
# Integrity: It is crucial that no one can tamper with the files stored on your system or while being transferred on the network.
# Availability: You want your laptop or smartphone to be available to use anytime you decide to use it.

## Common Security Weaknesses

##  Authentication & Weak Passwords

### What is Authentication?

Authentication is the process of **verifying a user's identity** before granting access.

### Types of Authentication

* **Something You Know** → Password, PIN
* **Something You Are** → Fingerprint, Face ID
* **Something You Have** → Phone, OTP, Security Token


##  Weak Passwords

Weak passwords are:

* Easy to guess
* Commonly used
* Based on personal information
* Reused across multiple accounts

### Examples

```text id="nuh48k"
123456
password
dragon
monkey
qwerty
iloveyou
```

Attackers use:

* Dictionary attacks
* Brute-force attacks
* Common password lists
##  Strong Password

A strong password should:

* Be long (12+ characters)
* Use uppercase & lowercase letters
* Include numbers
* Include special characters
* Be unique for every account

### Example

```text id="t95mnh"
LearnM00r
```

## Weak File Permissions

### Principle of Least Privilege

Users should only have access to the files they need.

> **Only the right people should access the right files.**

### Risks

* Unauthorized users can **read** private files.
* Unauthorized users can **modify** or **delete** files.

# Malicious Programs (Malware)

Malware can attack:

* Confidentiality
* Integrity
* Availability

## 🐴 Trojan Horse

* Pretends to be legitimate software.
* Gives attackers remote access.
* Can steal or modify files.

##  Ransomware

* Encrypts files.
* Files become unreadable.
* Attacker demands payment for the decryption key.

#  Key Points

* Authentication verifies identity.
* Weak passwords are easy to crack.
* Never reuse passwords.
* Follow the **Principle of Least Privilege**.
* Trojans give attackers unauthorized access.
* Ransomware encrypts files and demands ransom.
