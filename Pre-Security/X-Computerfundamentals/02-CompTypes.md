### TYPES OF COMPUTERS


# Laptop
A portable computer with a built-in screen and keyboard used for everyday computing.

# Desktop
A computer designed for use at a fixed location, offering sustained performance.

# Workstation
A high-performance computer designed for professional and technical tasks.

# Server
A computer that provides services, resources, or data to other computers over a network



# OTHER TYPES OF COMPUTERS

# Smartphone
A pocket-sized computer optimized for battery life and connectivity.

Examples:
 iPhone
 Android Phone

# Tablet
A touch-based computer with a larger screen than a smartphone.

Examples:
 iPad
 Drawing Tablet

# IoT Device (Internet of Things)
A network-connected device designed for a specific purpose.

Examples:
 Smart Thermostat
 Smart Doorbell
 Fitness Tracker

# Embedded Computer
A computer built inside another device to perform a specific task.

Examples:
 Coffee Maker Controller
 Automatic Door Sensor
 Lamp Dimmer Chip

# IoT vs Embedded

IoT Device:
 Connected to a network.
 Can send and receive data. 
EX = 
Smart Doorbell
↓
Sends video to your phone
↓
You can view it from anywhere
 
 Embedded Computer
 May not be connected to a network.
 Performs a specific task inside a device.
EX = 
Automatic Door Sensor
↓
Detects movement
↓
Opens door
